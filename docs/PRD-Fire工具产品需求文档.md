# FIRE 工具 — 产品需求文档（PRD）

> **FIRE** = Financial Independence, Retire Early（财务独立，提前退休）  
> 核心理念：积累足够资产，靠被动收入（利息、股息、租金等）覆盖生活支出，实现「靠利息生活」。

## 二、产品愿景与目标用户

### 2.1 产品愿景

为追求财务独立、希望「靠利息生活」的用户，提供**个性化、可量化、可追踪**的 FIRE 规划与进度管理工具，帮助用户明确目标、算清数字、看到进度，从而更有信心地执行长期储蓄与投资计划。

### 2.2 目标用户

- 已了解或认同 FIRE 理念，希望系统化规划的人
- 需要清晰看到「还要存多少、还要多少年」的人
- 希望根据个人情况（收入、支出、年龄、风险偏好）定制方案的人
- 偏好本地/隐私友好、可自定义、不依赖复杂云服务的人（可选方向）
- **典型画像**：中国大陆一线城市大厂员工（如腾讯），收入含工资、年终奖、RSU，资产分布在 A 股、港股、美股、基金等，需考虑五险一金、个税与长期调薪

**典型场景示例（腾讯员工）**：月薪 + 每年固定比例调薪、年终奖、多笔 RSU 分年归属；资产包括 A 股、港股（如持仓公司股票）、美股、国内公募基金、公积金、现金等；希望工具能根据「当前资产 + 未来每年工资与 RSU 归属」逐年递推，算出何时能达到 FIRE 目标（25 倍年支出等）。

### 2.3 核心价值

1. **算清你的 FIRE 数字**：基于个人支出与安全提取率，算出「需要多少资产才能 Fire」
2. **看清进度**：当前净资产 vs FIRE 目标，以及预估达成时间
3. **支持多种 FIRE 形态**：Lean / Normal / Fat / Coast / Barista 等
4. **可调参数、可复盘**：利率、通胀、支出变化、一次性大额支出等可配置

## 三、FIRE 核心概念（产品逻辑基础）

| 概念 | 说明 | 在产品中的用途 |
|------|------|----------------|
| **年支出** | 维持期望生活方式所需的年度总支出 | 作为计算 FIRE 目标的基础 |
| **FIRE 目标（FIRE Number）** | 达到财务独立所需的总资产 | 目标值 = 年支出 ÷ 安全提取率（如 4%） |
| **安全提取率（SWR）** | 每年从投资组合中安全提取的比例（常用 4%） | 用于由「年支出」反推「所需资产」 |
| **储蓄率** | 储蓄额 ÷ 收入 | 影响「多少年可达成 FIRE」 |
| **Coast FIRE** | 当前资产复利到退休年龄已够用，无需再追加投资 | 可算「已 coast」或「还需工作到何时」 |
| **Barista FIRE** | 用部分被动收入 + 少量工作覆盖支出 | 可支持「部分收入」场景 |
| **Lean / Fat FIRE** | 以年支出水平区分：极简 vs 较宽松生活 | 对应不同的「年支出」与「FIRE 目标」 |

## 三（补充）、中国大陆场景适配

以下约定使产品更贴合在中国大陆工作、生活与投资的用户（货币、社保、税负、投资渠道等）。

| 维度 | 约定与说明 |
|------|------------|
| **本位币** | 默认人民币（CNY），所有资产与目标统一折算或录入为 CNY；若存在多币种（如港币、美元），需支持汇率折算或手动录入「CNY 等价」 |
| **通胀假设** | 默认可参考国内 CPI 或个人感受设定（如 2%～3%）；退休后年支出可按该比例逐年增长 |
| **社保与公积金** | 收入侧：月薪为「税前」或「税后」需可配置；支持五险一金、个税扣减后得到「到手收入」。资产侧：公积金余额计入资产（可选是否计入 FIRE 资产）；未来社保养老金可作为「退休后补充收入」单独估算（可选模块） |
| **税务** | 工资薪金、年终奖、RSU 归属等在中国大陆的个税规则可简化建模（如累计预扣、年终奖单独计税等），或由用户输入「税后/到手」数值，工具主要做现金流与资产增长预测 |
| **投资市场** | 明确区分：**A 股**、**港股**（含沪港通/深港通）、**美股**（如通过 QDII、港股券商、境外券商等）、**基金**（国内公募：股基/债基/指基/货基等）。各市场资产可分别录入与汇总，便于按市场看占比与回报假设 |
| **汇率** | 港股（HKD）、美股（USD）等资产需按「当前汇率」或用户指定汇率折算为 CNY，用于统一净资产与 FIRE 目标比较；汇率可配置为固定值或手动定期更新 |

### 4.3 模块二：资产与负债（中国大陆 · 多市场与 RSU）

适配大陆用户及大厂员工常见的**多市场投资 + 股权激励**结构，资产需区分市场与类型，并支持多币种折算为 CNY。

#### 4.3.1 资产分类与录入

| 资产类型 | 说明 | 币种/折算 | 是否计入 FIRE | 优先级 |
|----------|------|-----------|----------------|--------|
| **现金及等价物** | 活期、定期、货币基金等 | CNY 或折算 CNY | 是 | P0 |
| **公积金余额** | 个人+单位缴存余额（可从公积金账户查询） | CNY | 可选（通常计入） | P0 |
| **社保个人账户** | 养老/医疗等个人账户余额（可选，用于更细的退休收入估算） | CNY | 可选 | P2 |
| **A 股** | 沪深股票、场内/场外持仓市值 | CNY | 是 | P0 |
| **港股** | 港股通或港券商持仓（如腾讯 0700.HK 等） | HKD → 按汇率折算 CNY | 是 | P0 |
| **美股** | 通过 QDII、港股券商、境外券商等持有的美股 | USD → 按汇率折算 CNY | 是 | P0 |
| **基金** | 国内公募：股票型/混合型/债券型/指数型/货币型等 | CNY | 是 | P0 |
| **RSU 已归属未卖出** | 已归属、仍持有的公司股票（按当前市价或保守价估值） | 按上市地（如 HKD/USD）折算 CNY | 是 | P0 |
| **RSU 未归属** | 见下文「RSU 授予与归属」：按归属计划与当前股价估算「未来可归属价值」；**MVP 默认计入资产**（未归属股数×单股估值，折算 CNY） | 同上 | **是（MVP 计入）** | P0 |
| **债券/银行理财等** | 债券、银行理财、保险现金价值等 | CNY | 是 | P1 |
| **应收款（别人欠我钱）** | 借出未收回的款项、预计可收回的债权等 | CNY 或折算 CNY | 可选（按可收回性决定是否计入 FIRE） | P0 |
| **房产（自住/投资）** | 自住房可勾选「不计入 FIRE」；投资性房产按估值计入 | CNY | 自住建议不计入 | P1 |

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 资产金额与快照日期 | 每条记录对应某日期的市值或估值；**MVP 全部为手动录入**，无自动拉取行情 | P0 |
| 多币种与汇率 | 港股(HKD)、美股(USD)等支持录入原币种 + 汇率，或直接录入「CNY 等价」 | P0 |
| 历史快照 | 支持多次录入同一类资产，形成「净资产随时间」曲线 | P1 |
| 是否计入 FIRE 资产 | 每类/每笔可勾选是否参与 FIRE 目标比较（如自住房、应收款按需勾选） | P0 |
| **数据输入（MVP）** | **仅支持手动输入**；不从银行/券商/账单导入；资产估值全部由用户录入 | P0 |

#### 4.3.2 RSU 未归属部分的处理方式

| 策略 | 描述 | MVP 选择 |
|------|------|----------|
| **仅作收入预测** | 未归属 RSU 不进入「当前净资产」，只在「收入与支出」中按归属计划生成未来各年「归属收入」现金流 | 后续可选 |
| **计入资产（期权价值）** | 按「未归属股数 × 当前股价 × 折扣系数」等估算为资产，与「归属时计入收入」逻辑协调（归属当年收入增加、未归属资产减少，避免重复） | **MVP 采用** |

**MVP 约定**：未归属 RSU **计入当前资产**（未归属股数 × 单股估值，折算 CNY）；归属计划仍用于生成未来各年「归属收入」参与现金流与达成年限计算。后续版本可增加开关「仅作收入预测 / 计入资产」供用户选择。

### 4.4 模块三：收入与支出（中国大陆 · 大厂薪酬结构）

收入侧需支持**月薪、年度调薪、年终奖、RSU 归属**等，并考虑**五险一金与个税**对到手收入的影响，以便准确计算「年储蓄」与未来多年现金流。

#### 4.4.1 工资与调薪（核心：复利式月薪增长）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **当前月薪（税前/税后）** | 支持选择「税前」或「税后」；若为税前，需结合五险一金与个税估算税后（见下） | P0 |
| **年度调薪比例** | 每年固定调薪比例（如 5%、8%）。**调薪后影响后续所有年份的月薪**：第 n 年月薪 = 当前月薪 × (1 + 调薪比例)^n | P0 |
| **月薪生效日期** | 当前月薪对应的基准日期（如「2025 年 1 月」），用于计算未来各年 12 个月的月薪序列 | P1 |
| **年薪（推算）** | 年工资 = 月薪×12（或按实际发薪月数）；未来某年 = 该年月薪×12，月薪已按调薪复利 | P0 |

#### 4.4.2 年终奖

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 年终奖金额 | 当前/典型年度年终奖（税前或税后，需与「月薪」口径一致） | P0 |
| 年终奖与调薪的关系 | 可选：年终奖是否随调薪比例同步增长（如「年终奖 = 固定 N 个月月薪」则随月薪增长） | P1 |
| 未来各年年终奖 | 用于年度现金流：年收入 = 该年月薪×12 + 该年年终奖 | P0 |

#### 4.4.3 RSU 授予与归属计划

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **授予（Grant）录入** | 每笔 RSU 授予：授予日、归属周期（如 4 年）、归属节奏（如每年 25%，或按公司具体 schedule） | P0 |
| **未归属股数** | 当前尚未归属的股数；随「归属计划」在未来的某年某月变为「归属收入」（按归属日股价或用户设定估值方式折算为 CNY） | P0 |
| **单股估值** | 未归属部分估值：可按「当前股价」或「保守折扣」（如当前价×0.9）；股价需支持按上市地（如港币/美元）与汇率折算 CNY | P0 |
| **归属收入计入现金流** | 每年「归属并变现」或「归属即计入收入」的金额，计入该年收入，参与该年储蓄与净资产增长（若未卖出，则资产侧已有持仓，避免重复计算；若默认归属即卖出，则归属额 = 该年收入增量） | P0 |
| **多笔 Grant 叠加** | 支持多笔 RSU 授予，每笔独立归属计划，系统汇总得到「未来各年 RSU 归属收入」曲线 | P0 |

说明：若用户选择「归属后继续持有」，则归属当年既增加「收入」又增加「资产」；若选择「归属即视为卖出并再投资」，则仅增加收入、再投资进入对应资产类别。产品可默认「归属收入计入当年收入，对应资产按持仓或再投资更新」。

#### 4.4.4 五险一金与个税（MVP：深圳比例 + 可调）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **内置比例（深圳）** | MVP 默认按**深圳市**五险一金比例与个税规则，从「税前月薪」「税前年终奖」推算税后到手；养老/医疗/失业/工伤/生育 + 公积金比例采用深圳常见取值（如公积金 5%～12% 可配） | P0 |
| **比例与规则可调** | 用户可在设置中**调整**各险种比例、公积金比例、起征点等，以适配个人实际缴存或其它城市（如北京、上海）；个税按累计预扣法简化计算，年终奖可选单独计税或并入综合所得 | P0 |
| 到手收入 | 年到手 = 月薪税后×12 + 年终奖税后 + 该年 RSU 归属收入（已折算 CNY）；用于与支出比较得到年储蓄 | P0 |

说明：深圳比例作为默认值，文档或产品内需注明「仅供参考，以实际工资条为准」；用户若更信任自己手工数字，可后续支持「覆盖为税后月薪/税后年终奖」直接录入。

#### 4.4.5 其他收入

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 副业/租金/理财利息等 | 其他主动或被动收入，可录入年金额或月金额，参与年收入汇总 | P1 |
| 收入可关联情景 | 不同情景下可用不同月薪、调薪、年终奖、RSU 假设 | P2 |

#### 4.4.6 支出

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 当前年支出 | 过去一年或月支出×12 的估算（CNY） | P0 |
| 退休后期望年支出 | 可与当前相同，或按「Lean/Normal/Fat」设不同档位 | P0 |
| 支出分类（可选） | 衣食住行、保险、医疗、娱乐等，便于细化与情景设定 | P1 |
| 支出增长率（通胀） | 与全局通胀率一致或单独设定，用于未来各年支出与 FIRE 目标（未来币值） | P1 |
| 大额支出事件（可选） | 如某年买房、子女教育一次性支出，影响该年净储蓄 | P2 |

#### 4.4.7 储蓄与储蓄率

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 年储蓄额计算 | 年收入（工资+年终奖+RSU 归属+其他）- 年支出；**未来各年**按该年收入与支出逐年计算 | P0 |
| 储蓄率 | 年储蓄 / 年收入，百分比展示（当前年 + 可选未来年份） | P0 |
| 达成年限计算 | 需支持「各年收入/支出/储蓄不同」的逐年现金流递推（见下 FIRE 计算模块），而非仅用固定年储蓄的简化公式 | P0 |

### 4.5 模块四：FIRE 计算与看板

#### 4.5.1 FIRE 目标计算

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 基础公式 | FIRE 目标 = 退休后期望年支出 ÷ 安全提取率（如 4% → 25 倍年支出） | P0 |
| 多目标 | 支持 Lean / Normal / Fat 多个目标金额（对应不同年支出档位） | P0 |
| 与当前净资产比较 | 进度 = 当前可投资净资产 ÷ FIRE 目标（百分比） | P0 |
| 考虑通胀（可选） | 目标退休年的「年支出」按通胀抬升，再除以 SWR，得到未来币值的目标 | P1 |

#### 4.5.2 达成时间估算

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **逐年现金流与资产递推** | 因存在**调薪（月薪逐年复利增长）、年终奖、RSU 分年归属**，年收入与年储蓄每年不同，需按「年」递推：每年末净资产 = 上年末净资产×(1+回报率) + 该年储蓄；直至某年净资产 ≥ FIRE 目标，得到达成年份 | P0 |
| 固定储蓄的简化公式 | 若无调薪、无 RSU，可用简化公式（附录）快速估算；有调薪/RSU 时以逐年递推为准 | P1 |
| 展示形式 | 如：「按当前节奏，预计在 203x 年 / 你 xx 岁时达成」；可选展示「各年净资产 / 收入 / 储蓄」表格或曲线 | P0 |

#### 4.5.3 Coast FIRE 计算（可选）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| Coast FIRE 目标 | 到目标退休年龄时，仅靠复利（不再投入）即可达到 FIRE 目标所需的「当前资产」 | P1 |
| 判断 | 若当前净资产 ≥ Coast 所需金额，则显示「已达成 Coast FIRE」 | P1 |
| 若未达成 | 可估算「再坚持投资多少年即可 Coast」 | P1 |

#### 4.5.4 进度看板与可视化

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 进度条 | 当前净资产 / FIRE 目标，百分比与进度条 | P0 |
| 关键数字一览 | 当前净资产、FIRE 目标、差距、预计达成年份 | P0 |
| 净资产趋势图 | 横轴时间，纵轴净资产（含历史快照 + 未来预测曲线） | P1 |
| 多情景对比表/图 | 不同 SWR、回报率、支出下的目标与达成年份对比 | P1 |
| 里程碑提示 | 如「已达成 25% / 50% / Coast FIRE」等 | P2 |

#### 4.5.5 Barista FIRE（可选）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 部分被动收入 + 部分工作收入 | 用户设定退休后「需要从资产提取的比例」与「工作收入占比」，反推所需资产 | P2 |
| 或：设定「退休后兼职年收入」，降低对资产提取的需求，从而降低 FIRE 目标 | P2 |

## 八、已定结论与开放点

以下为当前已定结论（按本次 PRD 调整）：

| 项 | 结论 |
|----|------|
| **数据输入方式** | **MVP 仅支持手动输入**；不从账单/银行/券商 CSV 导入；后续版本可预留导入能力。 |
| **资产估值** | **MVP 全部手动录入**市值/估值；不对接行情 API；后续可预留接口。 |
| **RSU 未归属** | **MVP 将未归属 RSU 计入当前资产**（未归属股数×单股估值）；归属计划仍用于未来各年归属收入与现金流。 |
| **五险一金与个税** | **MVP 按深圳市内置比例与个税规则**推算税后；比例与规则**支持用户调整**以适配实际或其它城市。 |
| **产品形态** | **Web 网页**（SPA），浏览器访问，数据本地存储。 |
| **每月资产快照** | **MVP 暂不支持**「每月更新资产快照」工作流与自动刷新进度/图表；**保留延展性**（数据模型与架构支持多时间点快照），后续大概率会做月度/年度复盘能力。 |

**仍可后续讨论**：多币种汇率为手动固定值还是未来支持拉取、RSU 未归属是否在后续版本增加「仅作收入预测」开关等。

## 九、附录：核心公式速查

- **FIRE 目标（4% 法则）**  
  `FIRE 目标 = 退休后期望年支出 ÷ 0.04`（即 25 倍年支出，单位 CNY）

- **达成年限（固定年储蓄时）**  
  设当前资产 \(A_0\)，**固定**年储蓄 \(S\)，年化回报 \(r\)，目标 \(T\)。  
  第 \(n\) 年末资产：  
  \(A_n = A_0(1+r)^n + S \cdot \frac{(1+r)^n - 1}{r}\)  
  求使 \(A_n \geq T\) 的最小整数 \(n\)。

- **达成年限（调薪 + RSU 等，年储蓄逐年变化）**  
  需**逐年递推**：  
  \(A_0\) = 当前可投资净资产；  
  第 \(t\) 年：收入\(_t\) = 该年月薪×12 + 年终奖\(_t\) + RSU 归属收入\(_t\)，支出\(_t\) = 该年支出（可按通胀增长），储蓄\(_t\) = 收入\(_t\) - 支出\(_t\)；  
  \(A_t = A_{t-1}(1+r) + 储蓄_t\)。  
  求使 \(A_t \geq T\) 的最小整数 \(t\)。其中月薪按「当前月薪 × (1+调薪比例)^t」增长。

- **Coast FIRE 所需当前资产**  
  设目标退休年龄距今年数为 \(N\)，年化回报 \(r\)，FIRE 目标为 \(T\)。  
  `Coast 所需资产 = T ÷ (1+r)^N`
